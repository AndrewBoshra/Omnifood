# Omnifood

A responsive marketing site for a fictional food delivery service.

## Stack

HTML · CSS · responsive layout with media queries

## Features

- Responsive across desktop, tablet and mobile breakpoints
- Sticky navigation and scroll-triggered animations
- Pricing, features and customer testimonial sections

## Running it

Open `index.html` in a browser.

## Notes

An early front-end project, built to practise responsive CSS.
